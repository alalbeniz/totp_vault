# Actualización Chrome Web Store — TOTP Vault v2.14.0

## Paquete

Subir en **Package → Upload New Package**:

`totp-vault-v2.14.0-cws.zip`

## Cambio principal

Se añade en Ajustes un enlace opcional a:

https://buymeacoffee.com/alalbeniz

El enlace abre Buy Me a Coffee en una pestaña nueva.

- No se integra widget ni SDK de Buy Me a Coffee.
- No se descarga ni ejecuta código remoto.
- No se añaden permisos nuevos.
- TOTP Vault no envía secretos, códigos ni datos de la bóveda a Buy Me a Coffee.
