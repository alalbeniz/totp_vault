## Release notes ES

Añadido soporte multiidioma en español e inglés. La extensión puede seguir el idioma de Chrome o usar el idioma elegido manualmente desde Ajustes. También se han localizado el selector inline, autorrelleno, QR, accesibilidad y mensajes de error.

## Release notes EN

Added multilingual support for Spanish and English. The extension can follow Chrome's language or use a language selected manually in Settings. The inline picker, autofill, QR import, accessibility labels, and error messages are also localized.
