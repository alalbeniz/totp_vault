# Actualización Chrome Web Store — TOTP Vault v2.15.1

## Paquete

Subir en **Package → Upload New Package**:

`totp-vault-v2.15.1-cws.zip`

## Cambios

- Nuevo layout de tarjetas TOTP basado en la opción C: identidad a la izquierda y código, visibilidad y contador en la misma fila principal.
- Mejor aprovechamiento horizontal y menos espacio en blanco.
- El contador circular cambia al color de aviso cuando quedan **5 segundos o menos**.

## Release notes ES

Rediseñadas las tarjetas TOTP para aprovechar mejor el espacio y dar más protagonismo al código. El contador cambia a un rojo suave cuando quedan 5 segundos o menos.

## Release notes EN

Redesigned TOTP cards to use space more efficiently and give the code more visual prominence. The countdown switches to a soft red when 5 seconds or less remain.

## Permisos y privacidad

Sin cambios de permisos ni tratamiento de datos respecto a v2.15.0.
